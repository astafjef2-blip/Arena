# 🏘️ Учёт аренды квартир

Одностраничное веб-приложение для частных арендодателей: учёт сдаваемых квартир, жильцов, договоров и арендных платежей. Работает полностью в браузере, без сервера и установки — достаточно открыть `index.html`.

## Возможности

- **📊 Обзор** — сколько квартир сдано/свободно, поступления за текущий месяц, ожидаемые платежи, суммарная задолженность, график дохода за 12 месяцев, списки просроченных и ближайших платежей, договоры с истекающим сроком.
- **🏠 Квартиры** — адрес, число комнат (студия = 0), площадь, базовая ставка, заметки, статус «Сдана / Свободна / Бронь», кнопка «Сдать» для быстрого оформления договора, поиск.
- **👤 Жильцы** — ФИО, телефон, документ, заметки; по жильцу считаются активные договоры и всего оплачено.
- **📄 Договоры** — квартира + жилец, дата начала, дата окончания (или бессрочный), ставка, день оплаты (1–28), залог; автоматическая проверка пересечения сроков по квартире; досрочное завершение.
- **💰 Платежи** — график платежей строится автоматически из договоров; отметка оплаты (дата, сумма — поддерживаются частичные оплаты, способ, комментарий); статусы «Ожидает / Просрочен / Частично / Оплачен»; фильтры по статусу, квартире и жильцу; ручное изменение суммы/срока платежа (например, за неполный месяц).
- **✨ Демо-данные** — одним кликом заполняется пример из 5 квартир, 4 жильцов и 5 договоров с историей платежей.
- **⬇️ Экспорт / ⬆️ Импорт** — резервная копия всех данных в JSON-файл и восстановление из него.

## Где хранятся данные

В `localStorage` вашего браузера — данные остаются после закрытия страницы и не уходят никуда наружу. Если данные нужны на другом устройстве или в другом браузере, воспользуйтесь «Экспорт» / «Импорт».

## Запуск

- Локально: просто открыть `index.html` в браузере (двойной клик), либо
- `python3 -m http.server 8000` в папке проекта → http://localhost:8000

Стек: чистые HTML/CSS/JS без зависимостей и сборки, один файл.
